This directory contains machine-readable operative identity records governed by the corresponding human-readable constitutive documents and repository history.

## Validation

Each `*.identity.json` record must validate against [`../schemas/functional-identity.schema.json`](../schemas/functional-identity.schema.json).

A record does not grant itself authority. Authority remains scoped to authenticated governance, current delegation, and the boundaries encoded in the record.
